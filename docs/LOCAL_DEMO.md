# دموی محلی

```bash
npm ci
npm run demo
```

پنل: http://localhost:3000 — روی «ورود سریع دمو» کلیک کنید.

اطلاعات ورود فقط برای دیتابیس نمایشی محلی: `demo@smart.local` / `DemoPreview!2026`.

دیتابیس PostgreSQL مستقل در `.demo/postgres` و پورت 55440 قرار دارد. API روی loopback پورت 3001 و پنل روی loopback پورت 3000 اجرا می‌شوند. داده‌ها ساختگی‌اند؛ هیچ اکانتی واقعاً متصل نیست. Worker/Redis استفاده نمی‌شود؛ محدودکنندهٔ درخواست در این حالت فقط در حافظهٔ پردازش محلی است و برای استقرار production نیست. مسیرهای اتصال تلگرام، شروع کمپین و Test Send با DEMO_ACTION_DISABLED مسدود شده‌اند.

این حالت entrypoint مستقل دارد؛ `.env` یا دیتابیس اصلی را تغییر نمی‌دهد. کلیدها و داده‌های دمو در `.demo` نگهداری می‌شوند و از Git/Docker خارجند. خروجی Next دمو نیز در apps/web/.next-demo جداست. بستهٔ embedded-postgres فقط وابستگی توسعه برای این پیش‌نمایش است؛ نیاز به نصب Docker ندارد.

توقف از ترمینال دیگر:
```bash
npm run demo:stop
```
بستن تب مرورگر، سرورها را متوقف نمی‌کند. پس از توقف، داده‌های نمایشی برای اجرای بعدی حفظ می‌شوند. حالت دمو و حساب آن را به VPS منتقل نکنید؛ استقرار واقعی از فایل‌ها و تنظیمات production جدا استفاده می‌کند.
